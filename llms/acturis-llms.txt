# Acturis

> Acturis is the UK's leading multi-tenant SaaS platform for general insurance brokers, insurers and MGAs — commercial and personal lines broking, e-trade and digital distribution, policy administration, claims, document management, premium finance and accounting — founded in 2000 by David McDonald and Theo Duchen and now serving 100,000+ users across 40+ countries through Acturis Group (UK, Germany, France, Canada). Acturis has **no public developer surface**: no developer portal, no API reference, no OpenAPI/Swagger/AsyncAPI/GraphQL artifact, and no self-serve onboarding. Integration is commercial and partner-gated — insurer extranets, Polaris imarket digital trading, and named bilateral work such as the Aviva claims Broker API.

## APIs

None published. Do not attempt to call an Acturis API from documentation you find online — none exists publicly.

- The only named API is the **Aviva claims Broker API** (announced 2024-12-13, built by Aviva with Acturis): a one-way transfer of individual claim records and status updates from Aviva's claims system into a broker's Acturis system, covering personal and commercial lines motor, property and liability. Free to brokers, but enabled only through an Aviva Claims Service Manager or an Acturis Account Manager. No endpoints, payloads, auth scheme or specification are published.
- Marketing copy claims an "API-enabled platform" (insurer page) and "API capabilities and two-way integration with third parties" (commercial lines page). Neither is backed by reference documentation.
- Acturis Canada's Broker Management System holds **CSIO API Security Standards Certification** (2026-01-26) — that API surface is real but is provisioned between Acturis and Canadian insurers, not published.

## How integration actually works

- Commercial agreement with Acturis (Account Manager provisioned), not signup.
- **Polaris imarket** digital-trading service for UK broker↔insurer transactions; Acturis has been integrated with imarket since May 2005 and Polaris lists it as an integrated broker system.
- Insurer extranets — Acturis builds and runs eight of the top ten UK insurer extranets.
- **CSIO XML / eDocs** standards in Canada (CSIO XML is licensed to CSIO by ACORD).

## Compliance

- PCI DSS and SOC 1 ISAE 3402 — independent audit and accreditation of the hosted platform (https://www.acturis.com/product/).
- GDPR — data stored at Acturis sites in London and Amsterdam (https://www.acturis.com/insurer/).
- CSIO API Security Standards Certification + Gold CSIO Standards Certification Rating, Acturis Canada, 2026-01-26.
